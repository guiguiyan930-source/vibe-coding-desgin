# 设计 Prompt 模板库

## 企业官网首页
```
Design a modern corporate homepage with a clean minimalist style.
Hero section with gradient background from #1E3A5F to #4A90D9.
Professional typography, clear call-to-action buttons.
White space, modern geometric shapes, subtle animations.
UI/UX design, Figma style, high resolution.
```

## 服务展示页面
```
Design a services page with card-based layout.
4 service cards with icons, titles, descriptions and feature lists.
Color palette: primary #1E3A5F, secondary #4A90D9, accent #E8F1F8.
Clean grid layout, hover effects, professional feel.
```

## 联系表单页面
```
Design a contact form page with split layout.
Left side: contact information (email, phone, address).
Right side: form with name, email, phone, company, subject, message fields.
Blue and white color scheme, rounded corners, modern form design.
```
