# 技术栈选择参考

## 前端技术栈

| 技术 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| React + Vite | 中大型项目 | 生态丰富、性能好 | 学习曲线陡峭 |
| Vue 3 + Vite | 中小型项目 | 易上手、文档友好 | 生态稍小 |
| Next.js | SEO 重要 | SSR/SSG 支持 | 复杂度较高 |
| HTML + Tailwind | 简单页面 | 零配置、轻量 | 功能有限 |

## 后端技术栈

| 技术 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| Node.js + Express | 全栈 JS | 开发效率高 | 单线程限制 |
| Python + FastAPI | 数据密集型 | 性能优秀 | 需要 Python 知识 |
| Java + Spring Boot | 企业级 | 稳定可靠 | 配置复杂 |

## 数据库选择

| 数据库 | 适用场景 |
|--------|---------|
| MongoDB | 灵活 Schema、快速开发 |
| PostgreSQL | 关系型数据、复杂查询 |
| MySQL | 传统应用、稳定可靠 |
